본 프로젝트는 기존 스네이크 게임에 외부 API를 연동하여 랭킹 시스템을 도입한 과제입니다. tkinter를 이용한 GUI 환경에서 구동되며, 플레이어의 점수를 서버에 기록하고 TOP 10 랭킹을 제공합니다.

1. 실행 방법 및 환경 설정 (API 키 입력 방식)
이 프로젝트는 `uv` 환경에서 동작하며, 외부 API와 통신하기 위해 반드시 환경 변수 설정이 필요합니다. 터미널에 `uv add requests python-dotenv`를 입력하여 의존성 패키지를 설치해 주세요.

.env 파일 생성 및 키 입력 형식
본 프로젝트는 보안을 위해 API 키를 소스코드에 직접 노출하지 않고 `.env` 파일을 통해 안전하게 불러옵니다[span_0](start_span)[span_0](end_span). 코드를 정상적으로 실행하고 랭킹보드 기능을 이용하려면, 프로젝트 최상위 폴더(`main.py`와 같은 위치)에 **반드시 `.env`라는 이름의 파일을 직접 생성**한 후, 아래와 같은 형식으로 텍스트를 작성하여 저장해야 합니다.

```env
API_KEY="여기에_icampus로_제출한_실제_API키_입력"
API_URL="실제_API_요청_주소"

.env 파일 안에 띄어쓰기 없이 변수명="값" 형태로 입력해야 python-dotenv 라이브러리가 이를 정상적으로 인식하여 HEADERS의 인증 수단으로 사용합니다.
(※ 실제 구동 시 사용하는 API Key 값은 깃허브에 업로드되는 것을 방지하기 위해 .gitignore로 차단하였으며, iCampus 과제 제출란에 별도로 제출하였습니다.)



2. 주요 코드 설명 (main.py)
API 통신 및 비동기 처리 (Threading)
네트워크 지연으로 인해 게임 화면이 멈추는 현상을 방지하기 위해, API 통신은 threading.Thread를 사용하여 메인 스레드와 분리된 백그라운드 환경에서 비동기적으로 실행됩니다.
fetch_rankings() (랭킹 조회): requests.get을 사용하여 서버에서 데이터를 가져옵니다. 응답받은 JSON 데이터의 다양한 키 구조에 유연하게 대응하여 리스트로 파싱한 뒤, 점수를 기준으로 내림차순 정렬하여 상위 10명을 추출합니다.
post_score() (점수 등록): 게임 오버 또는 전체 칸 클리어 시 자동으로 호출됩니다. requests.post를 사용하여 설정 화면에서 입력한 이름(name)과 최종 획득 점수(score)를 JSON 포맷으로 서버에 전송합니다. 전송이 완료되면 fetch_rankings()를 호출하여 최신 랭킹으로 화면을 갱신합니다.
환경 변수 및 헤더 구성
python-dotenv 라이브러리를 통해 .env 파일에 보관된 API_KEY와 API_URL을 안전하게 불러옵니다. 로드된 키는 HEADERS 딕셔너리에 담겨 HTTP 요청 시 인증 수단으로 사용됩니다.
게임 로직 및 UI 구성
tkinter 모듈을 사용하여 랭킹보드가 포함된 시작 화면과 실제 게임 화면을 구성합니다. 사용자는 게임 시작 전 플레이어 이름, 격자 크기(3x3 ~ 10x10), 그리고 뱀의 이동 속도(느림, 보통, 빠름)를 설정할 수 있습니다. 게임 루프는 root.after() 메서드를 활용하여 사용자가 설정한 속도에 맞춰 뱀을 이동시키며 화면을 지속적으로 갱신합니다.
